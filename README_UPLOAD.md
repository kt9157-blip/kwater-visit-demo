# kwater-visit-demo GitHub 업로드 간편 버전

이 버전은 GitHub 웹 업로드에서 문제가 되는 숨김 파일(.env.template, .gitkeep 등)을 제거한 버전입니다.

## GitHub에 올릴 파일

아래 3개 파일만 올리세요.

1. app.py
2. requirements.txt
3. CONFIG_SAMPLE.txt

실제로 Streamlit Cloud 실행에 반드시 필요한 파일은 app.py와 requirements.txt입니다.

## Streamlit Community Cloud 배포

1. Streamlit Community Cloud 접속
2. GitHub 로그인
3. Create app
4. Repository: kt9157-blip/kwater-visit-demo 선택
5. Branch: main
6. Main file path: app.py
7. Deploy 클릭
